# Git and GitHub Fundamentals

This course introduces Git as a distributed version-control system and GitHub as a platform for hosting and collaborating on Git repositories.

## Core topics

- Repositories, commits, and the working directory form the basic Git workflow.
- `.gitignore` and empty-directory conventions control what the repository tracks.
- Branches support parallel work; merging integrates changes and may require resolving conflicts.
- Stashing, tags, and rebase support common development and release workflows.
- GitHub hosts repositories and enables collaboration, including multi-user workflows.
- GitHub Desktop and VS Code provide graphical ways to work with Git.
